3PL运营平台静态原型

本原型覆盖 PC 端和小程序端的核心页面，聚焦客户要货、配送、入库、退仓、库存、审批和异常处理场景，并新增大小包装转换（大小码转换）全链路页面，对齐徐福记试点业务规则，可作为产品评审、UI深化和前后端协作的起点版本。

范围：3PL平台
终端：PC端 + 小程序端
页面：工作台 / 业务中心 / 大小码转换 / 库存 / 待办 / 发起 / 单据
大小码转换：BZSQ → BZTZ → BZ 三段式
形式：单文件静态原型
